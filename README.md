# International Sale Report & GenAI Streamlit App 📊🚀

An end-to-end AI/ML and generative AI application designed to process, analyze, and extract key business insights from international sales transactions, complete with an interactive Streamlit user interface.

## 📁 Repository Structure
* **`GenAI_Streamlit_App(final).ipynb`**: The notebook containing the Generative AI application framework and Streamlit deployment setup.
* **`International_Sale_Report.ipynb`**: The main data analysis notebook containing data exploration, modeling, and visualization.
* **`International sale Report.csv`**: The transaction dataset used for training and analysis (2.70 MB).

## 🚀 Getting Started
You can view and interact with the machine learning pipelines and the application development process directly inside Google Colab. 

### Running Locally
To run the notebooks or extract them as scripts on your local computer, make sure to install the required libraries first:

```bash
pip install -r requirements.txt
```

* **Google Colab** - Cloud development environment
